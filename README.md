## 🎪 About the Project

**WHY DID WE BUILD THIS?** is an intentionally terrible, hilarious, and chaotic interactive website built for college hackathons (celebrating the time-honored tradition of "Stupid Hackathons" and 3 AM coding delirium). 

It violates every single good UI/UX principle on purpose:
- 🎨 **Random Clashing Colors & Ugly Gradients** everywhere
- 🔤 **Mixed Fonts:** Comic Neue, Bungee, Press Start 2P, Monospace, and Papyrus
- 📢 **Unnecessarily Huge Text** right beside 8px micro-disclaimers
- 😂🔥💀😭🤡 **Way too many emojis**
- 🔘 **Buttons with Identity Crises:** From a 320px giant emergency button down to a 10px microscopic button
- 🏃‍♂️ **Runaway Dodging Buttons:** Good luck trying to click "NO, CLICK ME"
- 🤖 **Super Advanced Fake AI:** Trained on 47 Reddit arguments and a microwave manual
- 📊 **Ridiculously Inaccurate Statistics:** 73% More Confusing, 0 Problems Solved, 0.5 Brain Cells Remaining
- 👥 **Meet Our Team:** CEO ("Person Who Had The Idea"), CTO ("Person Who Opened VS Code"), Designer ("Person Who Picked Purple"), Developer ("Person Who Says 'It Works On My Laptop'"), and PM ("Nobody")
- 🚨 **The Giant Red "DO NOT PRESS" Button:** Complete with a dramatic modal that congratulates you for achieving nothing!

## 🚀 How to Run the Website

This website is built with pure Vanilla HTML5, CSS3, and JavaScript — **zero dependencies, zero installs, zero npm packages**.

### Option 1: Double-click to open
Simply open `index.html` in any modern web browser (Google Chrome, Microsoft Edge, Mozilla Firefox, Brave, Safari, etc.).

```bash
# Windows PowerShell
Start-Process "index.html"
```

### Option 2: Run with any local server
```bash
# Python 3
python -m http.server 8000

# or with npx serve
npx serve .
```
Then navigate to `http://localhost:8000`.
